## Screenshots and demos

The featured repositories did not provide a complete set of verified, current product screenshots or public deployment links for every project. The ChangeGuard README links to demo image filenames, but its UI migration notes describe those assets as needing re-capture from the newer UI. Those paths were not reused.

Instead, the profile uses original SVG system maps derived from repository documentation. They are marked as illustrative diagrams and link directly to source repositories. No fake screenshots, mock live URLs, or fabricated product metrics are presented.
